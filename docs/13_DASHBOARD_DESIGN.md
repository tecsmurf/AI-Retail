# Dashboard Design

## Design Philosophy
- **Dark theme** with glassmorphism effects
- **Purple brand color** (#a855f7) as primary accent
- **Micro-animations** for engagement
- **Information density** without clutter
- **SaaS-quality** visual polish

## Pages

### Executive Overview (Home)
- KPI cards: Visitors, Active, Conversion, Dwell Time, Revenue, Alerts
- Hourly footfall area chart
- Conversion funnel visualization
- Zone performance table
- Queue status metrics
- Demographics pie chart
- Top customer journey paths
- Anomaly center with real-time alerts
- Revenue by brand breakdown
- Multi-store comparison

### Components
- **StatCard**: Animated metric card with trend indicator
- **ConversionFunnel**: Stepped progress bars
- **ZoneTable**: Ranked zone performance
- **JourneyPaths**: Visual path with color-coded steps
- **AlertList**: Severity-tagged alert feed
- **CustomTooltip**: Branded chart tooltips

| Token | Value | Usage |

| Emerald 500 | #10b981 | Success/positive |
| Amber 500 | #f59e0b | Warning |
| Rose 500 | #f43f5e | Danger/alerts |

| bg-card | #16161f | Card background |

## Responsive Design
- Mobile: Single column, stacked cards
- Tablet: 2-column grid
- Desktop: 3-column + 6-column layouts
