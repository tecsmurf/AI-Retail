# Business Requirements

## Core Requirements
1. Process CCTV footage to extract customer behavior data
2. Track customers from entry to exit
3. Map customer positions to predefined business zones
4. Generate business events from CV detections
5. Reconstruct complete customer journeys
6. Correlate in-store behavior with POS purchases
7. Detect operational anomalies in real-time
8. Present analytics in a modern SaaS dashboard
9. Support multiple stores
10. Deploy on affordable cloud infrastructure

## Analytics Requirements
- Footfall: hourly, daily, weekly, monthly
- Zone: visits, dwell time, popularity
- Conversion: visitor → purchase funnel
- Queue: wait time, abandonment
- Journey: top paths, conversion paths
- Revenue: per visitor, per zone, by brand
- Demographics: gender, age distribution

## Non-Functional Requirements
- Real-time updates via WebSocket
- Mobile-responsive dashboard
- <3 second API response time
- Structured logging
- Docker containerization
- Production-ready error handling
